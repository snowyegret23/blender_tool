# Blender Tools

Five independently installable Blender add-ons. The original add-on source code and licenses are preserved in their own directories.

| Add-on | Purpose |
| --- | --- |
| [EZDeleteChildBone](addons/EZDeleteChildBone/) | Delete child bones of selected bones. |
| [EZLoop](addons/EZLoop/) | Quick access to LoopTools Flatten, Relax, and Space. |
| [EZLoopTools](addons/EZLoopTools/) | Select loops from faces and apply LoopTools operations. |
| [EZQuadRemeshes](addons/EZQuadRemeshes/) | Quad remeshing using Blender's QuadriFlow operator. |
| [EZRemeshes](addons/EZRemeshes/) | Remesh using far or close vertex connections. |

## Installation

These add-ons declare Blender 3.6 as their minimum version. To install one, ZIP its folder under `addons/` (with the add-on folder as the top-level directory in the ZIP). In Blender 3.6, open **Edit → Preferences → Add-ons → Install**, select the ZIP, then enable the add-on. Enable Blender's **Mesh: LoopTools** before using EZLoop or EZLoopTools.
